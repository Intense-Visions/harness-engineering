feat: review provenance stamp (shift-left pipeline fidelity, unit 3 of 5).

- **Provenance.** New `harness review-provenance render --session <slug>` prints the stamp autopilot places in the PR body: one row per review the session calls for (`MISSING` for one with no directory) and one per review directory (a directory without a readable receipt is a row that says so), with reviewers whose findings file loaded, coverage, the receipt gate re-run for every review (and, on the final row, the number of commits after the reviewed head, whether the gate passed, failed or was overridden), blocking findings with dismissals and earlier rounds, and an Override cell that starts with the number of overrides and dismissals. Nothing is cut without a mark. Overrides and dismissed findings are typed records in autopilot's `decisions[]` (`ReviewDecisionRecord`); each carries the round it was taken in and applies only to that round's receipt, and who decided (`decidedBy`: `human`, `audited` or `unaudited`), which the stamp prints beside every decision and flags in the Blocking cell for a dismissal that is not the human's or audited. A decision that belongs to no review is named in a note, and one recorded for a review without a receipt is shown on that row (`unknown` when the decisions could not be read). Only a decision's declared fields are read. Review labels are `phase-N` and `final-all` only, and free text is made inert (no markup, link, mention, issue reference, math or invisible character; `;` is encoded, since it separates decisions).
- **One reader of the session state.** `autopilot-state.json` is read once per render, through `readSessionReviewState`, which applies `AutopilotSessionStateSchema` (now exported from core's state module with `AUTOPILOT_STATE_FILENAME`) field by field; the receipt gate's starting commit comes from the same reader. `startingCommit` must be a full sha.
- **A stamp is read only as the page shows it.** `parseProvenanceStamp` reads a stamp only when its markers stand on lines of their own after an empty line, the heading is the line after the opening marker, and none of it is inside an HTML comment, a code block or a raw HTML block, so a stamp hidden in a link reference definition, a paragraph or a fence is not read. It reads rows only under the table header and notes only after the table, and refuses an Override cell longer than the renderer can write.
- Autopilot's state contract (`AutopilotSessionState`, `AutopilotPhaseEntry`) is exported from `@harness-engineering/types`. Dismissing a blocking finding is a judgment pause that never auto-resolves unless the self-audit ran and agreed, and a final review ends `passed` only when nothing of it was set aside in any round: with a dismissal it ends `passed-with-dismissals`, with a gate or findings override `overridden`.
