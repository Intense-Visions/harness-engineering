feat: review provenance stamp (shift-left pipeline fidelity, unit 3 of 5).

- **Provenance.** New `harness review-provenance render --session <slug>` prints the stamp autopilot places in the PR body: one row per review the session calls for (`MISSING` for one with no directory, `skipped (empty)` or `skipped (dropped)` for one a `skipped` decision covers, with an `empty` skip's range recomputed at its head: `skipped (empty; range not empty)` or `skipped (empty; unverified)` when it is not empty or cannot be checked) and one per review directory (a directory without a readable receipt is a row that says so), with reviewers whose findings file loaded, coverage, the receipt gate re-run for every review with the reviewed head allowed to be an ancestor of HEAD and the working tree not checked (and, on the final row, the number of commits after the reviewed head, whether the gate passed, failed or was overridden, or, when it has no receipt that was read, after the base the final gate would demand: the merge base with the default branch, else the starting commit), blocking findings with dismissals and earlier rounds, and an Override cell that starts with the number of overrides and dismissals. Nothing is cut without a mark. Overrides, dismissed findings and skipped reviews are typed records in autopilot's `decisions[]` (`ReviewDecisionRecord`, a union keyed on `kind`); each carries the round it was taken in and applies only to the receipt of that round as the gate counts it from the archives, and who decided (`decidedBy`: `human`, `audited` or `unaudited`), which the stamp prints beside every decision and flags in the Blocking cell for a dismissal that is not the human's or audited. A decision that belongs to no review is named in a note, and one recorded for a review without a receipt is shown on that row (`unknown` when the decisions could not be read). Only a decision's declared fields are read. Review labels are `phase-N` and `final-all` only, and free text is made inert (no markup, URL, mention, `#`/`GH-` issue reference, math or invisible character; `;` is encoded, since it separates decisions).
- **One reader of the session state.** `autopilot-state.json` is read once per render, through `readSessionReviewState`, which applies `AutopilotSessionStateSchema` (now exported from core's state module with `AUTOPILOT_STATE_FILENAME`) field by field; the receipt gate's starting commit comes from the same reader. `startingCommit` must be a full sha.
- **A best-effort reader of an unauthenticated stamp.** `parseProvenanceStamp` reads a stamp only when its markers stand on lines of their own after an empty line, the heading is the line after the opening marker, and none of it is inside an HTML comment, a code block or a raw HTML block, so a stamp hidden in a link reference definition, a paragraph or a fence is not read. It fails closed on the constructs it knows: before the body's last marker, `<details` or `</details` anywhere, an HTML comment opener sharing its line with a backtick, leaving a comment open without starting its line or reopening one after a `-->`, a line starting with `<noscript`, `<template`, `<select` or `<rp`, an HTML block holding a line that opens a fence, a raw HTML block or a comment, or a fence in a list item or quote it may outlive makes the body `ambiguous` and nothing is read; an ordinary PR body still reads. Blank is spaces and tabs only, as in CommonMark, and the scan is linear in the body's length. It does not render the page: a body crafted to show one stamp and hide another is not defended against, since whoever can write the body can write any stamp, and the stamp is shown as stated, not verified. A body that shows two or more stamps is `conflicting` and none is read, and a body over 262144 characters is `too-large` and not read; each is a state of its own, never "no stamp". A line indented four or more columns is never a row. It reads rows only under the table header and notes only after the table, and refuses an Override cell longer than the renderer can write.
- Autopilot's state contract (`AutopilotSessionState`, `AutopilotPhaseEntry`) is exported from `@harness-engineering/types`. Dismissing a blocking finding is a judgment pause that never auto-resolves unless the self-audit ran and agreed, and a final review ends `passed` only when nothing of it was set aside in any round: with a dismissal it ends `passed-with-dismissals`, with a gate or findings override `overridden`.
