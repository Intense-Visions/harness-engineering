feat: review fix rounds (shift-left pipeline fidelity, unit 2 of 5).

- **Fix rounds.** New `harness check-review-receipt --archive-round <review-dir>` archives an ended round into `round-R/` and prints the next round. A review that runs again after a fix is a new round recorded in the receipt (`round`, `priorRounds`); the round is 1 + the archived rounds, so a failed mechanical phase or a crash keeps it. The gate fails a `round` or `priorRounds` that does not match the `round-R/` archives beside the receipt (`ROUND_MISMATCH`, `PRIOR_ROUNDS_MISMATCH`), recounting each prior round's blocking count from its archived findings files (each file once; when one cannot be read, the archived receipt's own count is used).
- **Only a fix commit starts a round.** `--archive-round` refuses, moving nothing, a directory with no `receipt.json` (a round that wrote none is not a round), a path that is not a review directory (`phase-N` or `final-all` under `.harness/sessions/<slug>/reviews/`, or a directory directly under `.harness/reviews/`), a HEAD that is still the head the ended round reviewed, and archives not numbered `round-1` to `round-(R-1)`. It also refuses a `receipt.json` that is not a regular file, and one naming a findings file that is not a regular file directly in the review directory. It moves the files through a staging directory, `receipt.json` last, and moves them back on an error (`receipt.json` first), so an error archives the round whole or not at all. An interruption (the process dies) leaves `.round-R.partial` and the gate fails `ROUND_ARCHIVE_INTERRUPTED` while it exists (also beside a missing or invalid receipt). The next `--archive-round` completes the archive when the staging directory holds `receipt.json` and every findings file it names, even if a newer attempt has written files into the review directory since (they stay; that attempt's receipt is rewritten as the next round); with no `receipt.json` staged it moves the files back and archives again. It refuses a staging directory that is not the next archive's, a staged receipt that is unreadable or names a findings file the staging directory lacks, and, when moving files back, a name the review directory also holds. The gate fails a round after the first at the head the round before it reviewed (`ROUND_SAME_HEAD`) and archives numbered out of sequence (`ROUND_MISMATCH`). A review run again at the same head stays in its round and overwrites its files.
