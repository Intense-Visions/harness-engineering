## 3. Skill-body authoring discipline

| Measure                                                   | mattpocock/skills                                                                                                                                                                           | Harness (tier-1+2)                                                                                                                                                                                                                                |
| --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Negation density (lines with NOT/Never/STOP/Do not/Don't) | 52 / 1,854 = **2.8%** [UNVERIFIED]                                                                                                                                                          | 1,128 / 26,908 = **4.2%** (1.5x) — method below                                                                                                                                                                                                   |

Prompt the **positive**" (`writing-for-agents/SKILL.md`) [UNVERIFIED]                  | None found. Harness _mandates_ negative framing: `## Red Flags`, "If you catch yourself... | Pruning discipline                                        | Named concept "sediment"; prune no-ops, duplicated sources, environment-derivable content (`writing-for-agents/SKILL.md`) [UNVERIFIED]                                                      | Skill validator is **additive only**: `packages/cli/src/commands/skill/validate.ts:35-56` requires h1 + `BEHAVIORAL_REQUIRED_SECTIONS` + `RIGID_SECTIONS`; no size, density, or no-op check                                                       |
| "Leading words" / concept anchors                         | Deliberate short terms (frontier, seam, tracer bullet, fog of war, deep module) [UNVERIFIED]                                                                                                | Cognitive modes, EXISTS/SUBSTANTIVE/WIRED, tiers — present but not a stated authoring technique                                                                                                                                                   |

**Negation-density method (harness side), reproducible at `91f09fd17`.** File set: the 90 `agents/skills/claude-code/*/SKILL.md` files whose sibling `skill.yaml` declares `tier: 1` or `tier: 2`. Denominator: 26,908, the total newline count of those same 90 files. Numerator: matching lines from `grep -cE "NOT|Never|STOP|Do not|Don't"` — case-**sensitive**, substring rather than word-bounded, per-file counts summed — which is **1,128**, i.e. **4.19%**.

Sensitivity of that numerator to the pattern, over the same 90 files: word-boundary-anchored (`\bNOT\b|\bNever\b|\bSTOP\b|\bDo not\b|\bDon't\b`) gives 1,101 (4.1%); case-**insensitive** `never|stop|do not|don't`, dropping bare "not", gives 1,877 (7.0%); case-insensitive including bare "not" gives 3,883 (14.4%). An earlier draft published 1,792 / 26,908 = 6.7% (2.4x); that numerator could not be reproduced from the stated pattern by any variant tried here, so the table carries the figure the stated method actually yields. The direction of the comparison survives every variant — harness is at least 4.1% against mattpocock's reported 2.8% — but the published multiple is 1.5x, not 2.4x.

Observation: harness's authoring rules accrete required sections into every skill; mattpocock's authoring rules subtract. The 2026-04 agent-skills ADR made `Common Rationalizations` mandatory — the opposite direction from mattpocock's negation principle. Neither side has measured which direction produces better agent behavior.

## 7. Where harness is categorically stronger (no adoption question)

Mechanical enforcement, state, verification depth, knowledge graph, orchestration/fleets, multi-persona review, blast radius, telemetry, rollback, roadmap sync. mattpocock/skills has none of these by design ("small, easy to adapt, and composable" [UNVERIFIED]). These were already judged harness-better in the 2026-08-10 matrix; this pass confirms that and does not revisit them.

## 8. Facts relevant to the decision

1. Harness's always-loaded description cost is ~11x mattpocock's (24.6k measured vs a reported 2.3k chars), with none of it written as trigger phrasing. The harness term is measured (section 2); the mattpocock term is [UNVERIFIED] and may not have been measured the same way, so the multiple cannot be tightened from this side alone.
2. Harness's tier-1/2 bodies are ~3-5x longer and ~1.5x more negation-dense (4.2% measured against a reported 2.8%); the harness skill validator mechanically _requires_ accretion and checks nothing about size or density.
3. Neither side measures skill _behavior_ (does the right skill fire; does following it produce the right outcome). Harness measures adoption; mattpocock measures nothing.
4. Harness has no **implemented** rejected-idea record, which is directly relevant to this very session: discovery found a prior pass on the same repo that the human did not remember. The gap is already tracked as roadmap item #1620 (rejection ledger, planned), so the adoption question here is how to build it, not whether it is known.
5. Five discrete per-skill techniques (repro-command gate, seams, vertical slices, project glossary, deep-module vocabulary) have no harness counterpart; one (frontier interviews) is already filed.
