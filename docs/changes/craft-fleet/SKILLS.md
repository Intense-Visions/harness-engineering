# Skill Advisor — craft-fleet

Signals extracted from the spec: autonomous orchestration, LLM-judgment craft critique, ceiling-raising quality elevation, 3-axis finding vocabulary, noise floor, mechanical elevate/file routing, behavior-preserving refactoring, net-improvement re-critique, tiered elevation-PR / filed-roadmap-item terminal, batch fan-out, worktree isolation, all-OS-CI verification, batch human review, taste-calibration gate, skill authoring.

## Apply

- **harness-refactoring** — the real per-target elevation pipeline; its tests-green-before-and-after Iron Law, per-step commit trail, and "revert if it introduced no improvement" rule are the anti-churn envelope craft-fleet composes rather than reinvents.
- **naming-craft / code-craft / copy-craft / test-craft** — the only four domains with elevation-eligible surfaces (their findings land in source the test suite guards, and `copy-craft` only on internal-facing prose); composed in SELECT for the queue and re-run twice **by VERIFY** for net-improvement evidence, never by the dispatch subagent.
- **docs-craft / knowledge-craft / spec-craft** — prose-surface domains, file-only: no skill applies prose-quality edits under a safety envelope, and a ratified ADR is never edited at all.
- **api-craft / cli-ergonomics-craft / security-craft / harness-design-craft** — file-only domains; composed for the queue, never elevated, because every surface they critique is a published contract, a security posture, or has no craft-driven write path.
- **harness-skill-authoring** — author the new skill in the rich format (required sections, tier, Rationalizations to Reject).

## Reference

- **cleanup-fleet** — the floor twin craft-fleet mirrors: same queue-shaped sweep, opposite epistemics (rule-based objective vs advisory judgment); its convergence re-scan is the direct ancestor of craft-fleet's net-improvement re-critique.
- **bug-fleet** — the closest tiered-terminal analogue (fix PRs + filed issues, routing on change risk rather than finding severity); its reproduction bar is the structural ancestor of the cited-finding bar.
- **test-fleet / cicd-fleet** — the other quality-queue siblings sharing the documented spine (`docs/reference/fleet-family.md`).
- **harness-roadmap-pilot** — reuse its impact-scoring to order targets by composite tier × impact (SELECT).
- **align-design-system** — considered and rejected as a design-token elevation path: it consumes rule-based `DRIFT-*` findings that carry no craft cite, so wiring it in would require inventing the finding translation the Iron Law forbids.

## Consider

- **manage_roadmap (MCP)** — the filing mechanism for the `file` tier; each item carries its cited finding, rubric, and location.
- **craft-pipeline** — the craft orchestrator is not built; craft-fleet composes the individual craft skills directly and takes no dependency on it.
- **pr-fleet** — the downstream lander for the verified elevation-PR batch; craft-fleet never merges.
- **The Workflow primitive** — a future deterministic/resumable execution substrate for DISPATCH (named as an upgrade per the fan-out ADR, not v1).
